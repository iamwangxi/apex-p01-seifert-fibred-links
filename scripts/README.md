# Exact finite diagnostics

[Overview](../README.md) · [Proof and scope](../proof/scope.md)

Run with Python 3 and its standard library, from any working directory:

```text
python3 -B scripts/run_all.py
```

The displayed command assumes the repository root; alternatively invoke the runner by its full path. Each checker derives paths from its own file and writes **only its named JSON beside itself**. It has no network, package or external-source-file dependency. No random sampling or machine-dependent timing is included in the output.

- `exact_checks.py` → `exact_checks.json`: 81,088 bounded free-product products; 9,860 Jordan-feature partitions and 72,616 peripheral comparisons; 40 double-cover profiles; exact left/right probes and nine feasible subgraphs of the double-lens example; 121 rational flows, 536 threshold probes, 400 reference and 319 root comparisons, 121 zero-support checks, and 187 exact simplex recoveries.
- `independent_topology.py` → `independent_topology.json`: 729 genuine embedded arc classes generated by pure-braid squares through depth six, with eight cone-order profiles (including an extra non-coprime control outside the classified family); an arbitrary-word quotient negative control; independently eliminated abelian coordinates for the Jordan/peripheral checks; and explicit double-cover genera.
- `independent_carrier.py` → `independent_carrier.json`: exact polyline embeddings, connected regions rebuilt by forest-cycle winding signatures for each support, rational Gaussian-elimination potentials, and separately propagated whole-complement indices. Four mother graphs cover disconnected and connected supports, non-disk outside regions, nested cycles, a forced bridge and two marked cones. The run covers 260 feasible supports, 904 ordered matching-pair comparisons, 1,577 rational flow samples, 5,918 threshold probes, 4,569 reference comparisons, 4,549 root comparisons, 1,577 zero-support and 1,370 common-face comparisons, and 3,107 exact simplex recoveries. An actual embedded-band subfamily checks auxiliary-constant collisions, including collisions at phase zero.

The independent programs were originally written in separate fresh-context adversarial reviews; their mathematical functions remain separate implementations. Neither imports or executes the author's checker. Packaging changed only path/output conventions, documentation and provenance fingerprints. Their JSON fingerprints refer to the proof files in this package, not to external working files. A script's own SHA-256 is also recorded.

The free-product checks are bounded in conjugator length and sampled in cone order; the proof treats arbitrary orders and paths. The graph calculations compare two representative-width algorithms sharing input geometry; the geometry is checked separately, but this does not independently establish the minimum over all three-dimensional isotopies. The ordinary ambient-isotopy theorem and PS Proposition 3.2 remain written/literature inputs. No finite check establishes an exhaustive classification or a general theorem by extrapolation. The arbitrary intersecting-band PL normaliser and complete finite-parameter procedure have not been fully implemented.
